# Reference codebases (read-only)

Third-party repositories collected for studying while building Apex. Not part of the Apex repo.
The annotated index (what each one is good for, licences, rules) is in
`../Fitbit-air-app/docs/REFERENCES.md`.

- `design/` — **pulse-mobile-0.5.0** is the chosen UI/UX reference (plus its APK and a newer main snapshot)
- `android-kotlin/` — Android/Kotlin apps and Google's official Health Connect samples
- `fitbit-google-health/` — Fitbit Web API / Google Health API clients and data tools
- `whoop-style-apps/` — other recovery/strain apps for product and UX ideas
- `_duplicates/` — an identical copy and an older snapshot; safe to delete

Their `CLAUDE.md` / `AGENTS.md` files describe those projects only and are not instructions for Apex.
