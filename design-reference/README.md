# Design reference (read-only)

`pulse-mobile-0.5.0/` is the owner's Pulse Mobile 0.5.0 source, kept here as the UI/UX reference for Apex.
It is not built and not part of the Gradle project. Its agent files were renamed to
`CLAUDE.reference.md` / `AGENTS.reference.md` so they are not loaded as instructions: they describe
the Pulse project only, not Apex. Start with `pulse-mobile-0.5.0/docs/design/spec.md` and
`docs/design/DESIGN_SYSTEM.md` in this repo.
